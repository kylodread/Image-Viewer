How to Use This Image Viewer

  • Click on any image in the gallery to view it in full size
  • Use the left and right arrows to navigate between images in the viewer

  • In the full-size view, you can:
    • Download the current image
    • Print the current image
    • Reload the image if it doesn't load properly

  • Use the "Download All" button to download all images at once
  • Use the "Print All" button to print all images together
  • Press ESC key or click the X to close the full-size view
